# Build plan (time-boxed)

1. Pick a narrow task: evidence-backed research over a small tool surface.
2. Implement the loop directly: observe state, ask for one action, validate, execute, checkpoint, repeat.
3. Make failures visible and recoverable: bounded retries, error feedback, atomic state, hard budgets.
4. Evaluate mechanisms rather than prose quality using deterministic plans and injected faults.
5. Document one reproducible run, limitations, and the next highest-value improvements.

Deliberate non-goals: a general agent framework, browser automation, embeddings, multi-agent orchestration, and a production crawler.
